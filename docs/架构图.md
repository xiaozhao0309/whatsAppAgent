## 4. 进程内运行时结构

```mermaid
graph TB
    subgraph PROC["uvicorn 单进程 (--workers 1)"]
        direction TB
        subgraph ASGI["FastAPI / ASGI"]
            ROUTES["路由<br/>POST /webhook<br/>POST /ask<br/>GET /health<br/>POST /admin/ingest"]
            LIFESPAN["lifespan 启动钩子<br/>ensure_collection()<br/>embed_one('warmup')"]
        end

        subgraph GLOBAL["模块级单例（import 时创建）"]
            SESS["session_store<br/>SessionStore"]
            IDEM["idempotency<br/>IdempotencyGuard"]
            RL["rate_limiter<br/>RateLimiter"]
            ULOCK["_user_locks<br/>dict[WAID → Lock]"]
            QCLIENT["QdrantClient<br/>(本地文件单例)"]
            EMB["SentenceTransformer<br/>(lru_cache 单例)"]
        end

        subgraph BG["BackgroundTasks 线程池"]
            T1["_handle_serialized(用户A)<br/>持有用户A锁"]
            T2["_handle_serialized(用户B)<br/>持有用户B锁"]
            T3["..."]
        end
    end

    ROUTES --> BG
    BG --> SESS
    BG --> IDEM
    BG --> RL
    BG --> ULOCK
    BG --> QCLIENT
    BG --> EMB
    LIFESPAN --> QCLIENT
    LIFESPAN --> EMB

    classDef asgi fill:#e8f0fe,stroke:#4285f4
    classDef sing fill:#e6f4ea,stroke:#34a853
    classDef bg fill:#fef7e0,stroke:#f9ab00
    class ROUTES,LIFESPAN asgi
    class SESS,IDEM,RL,ULOCK,QCLIENT,EMB sing
    class T1,T2,T3 bg
```

**关键点**：
- 所有状态（会话、幂等、限流、用户锁、Qdrant client、embedding 模型）都是**模块级单例，在同一进程内共享**。
- 这就是为什么必须 `--workers 1`：多 worker = 多进程 = 多份内存，去重/会话/限流会失效。
- 不同用户的后台任务可并行，但**同一用户的任务被用户锁串行化**。

## 6. 数据流：一条消息的完整旅程

```mermaid
flowchart TD
    START([客户发送 WhatsApp 消息]) --> A[Twilio POST /webhook<br/>MessageSid, From, Body]
    A --> B{同步幂等<br/>seen_or_mark?}
    B -->|已见过| DROP([返回 200 丢弃])
    B -->|首次| C[add_task 后台处理<br/>立即返回 200]

    C --> LOCK[获取该用户锁<br/>同一用户串行]
    LOCK --> LEN{长度 ≤ 上限?}
    LEN -->|超长| S_LONG[回发 MESSAGE_TOO_LONG]
    LEN -->|是| RL{限流允许?}
    RL -->|超限| S_RL[回发 RATE_LIMITED]
    RL -->|是| CMD{是指令?}

    CMD -->|help/reset/greeting/<br/>feedback/handoff| DOCMD[执行指令分支<br/>回发对应文案]
    CMD -->|普通问题| SESS{会话状态?}

    SESS -->|absent 新用户| WELCOME[回发欢迎语]
    SESS -->|expired 过期| RESTART[回发已重新开始]
    SESS -->|active| RAG
    WELCOME --> RAG[读会话历史<br/>pipeline.answer]

    RAG --> KB{知识库为空?}
    KB -->|是| EKB[回发 EMPTY_KB]
    KB -->|否| EMB[embed 问题]
    EMB --> SEARCH[Qdrant 检索 top_k]
    SEARCH --> SCORE{最高分 ≥ 阈值?}
    SCORE -->|否| NOMATCH[拒答 NO_ANSWER<br/>miss_streak+1]
    SCORE -->|是| LLM[拼 system+历史+问题<br/>调 Ark LLM]
    LLM --> SELF{LLM 自陈无内容?}
    SELF -->|是| NOMATCH
    SELF -->|否| OK[截断答案 + 附来源 + 反馈提示]

    NOMATCH --> STREAK{miss_streak ≥ 2?}
    STREAK -->|是| HANDOFF[触发转人工<br/>通知值班号]
    STREAK -->|否| SEND
    HANDOFF --> SEND[回发客户]
    OK --> WRITETURN[写入会话 user+assistant]
    WRITETURN --> SEND
    DOCMD --> SEND
    S_LONG --> SEND
    S_RL --> SEND
    S_END([结束])
    EKB --> SEND
    SEND --> S_END

    classDef decision fill:#fef7e0,stroke:#f9ab00
    classDef action fill:#e6f4ea,stroke:#34a853
    classDef stop fill:#fce8e6,stroke:#ea4335
    class B,LEN,RL,CMD,SESS,KB,SCORE,SELF,STREAK decision
    class DROP,S_END stop
```

## 7. 目录结构

```text
whatsAppAgent/
├── app/
│   ├── main.py            # FastAPI 入口 + webhook 编排（接入层）
│   ├── config.py          # 环境变量配置（单一入口）
│   ├── channel.py         # Twilio 收发封装
│   ├── session.py         # 会话管理（内存，TTL/轮数/截断/miss/反馈去重）
│   ├── guards.py          # 幂等、限流、长度校验
│   ├── commands.py        # 指令识别（help/reset/handoff/feedback/greeting）
│   ├── handoff.py         # 转人工：组装上下文 + 主/备值班号
│   ├── observability.py   # request_id、号码脱敏、结构化日志
│   ├── responses.py       # 面向客户的话术文案
│   ├── rag/
│   │   ├── pipeline.py    # 检索 + 阈值 + 多轮 + LLM 生成（核心）
│   │   ├── embeddings.py  # 本地 sentence-transformers 向量化
│   │   ├── store.py       # Qdrant 封装（search/upsert/count/clear）
│   │   ├── chunking.py    # 文档切片
│   │   └── ingest.py      # 全量入库
│   └── sample_docs/       # 知识库源文档（.md/.txt）
├── tests/                 # pytest 单元测试（28 个）
├── scripts/ingest.py      # 命令行入库
├── specs/001-whatsapp-rag-assistant/   # Spec Kit 规格/计划/任务
├── docs/                  # 需求文档、决策记录、时序图、架构图（本文件）
├── data/qdrant/           # Qdrant 本地数据（gitignore）
├── .env                   # 真实密钥（gitignore）
├── .env.example           # 配置模板
└── requirements.txt
```
