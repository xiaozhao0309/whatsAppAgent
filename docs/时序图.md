# WhatsApp 企业知识问答助手 — 时序图

本文档基于当前代码（`app/main.py`、`app/rag/pipeline.py`、`app/handoff.py` 等）绘制核心流程的 Mermaid 时序图，便于快速理解系统行为。

- 同步阶段（webhook 内立即执行）：幂等检查，然后立即返回 HTTP 200。
- 后台阶段：同一用户在**用户锁内串行**处理：长度→限流→指令→会话→RAG→回发。

---

## 1. 主流程：正常问答（命中知识库）

```mermaid
sequenceDiagram
    autonumber
    participant U as 客户 WhatsApp
    participant T as Twilio
    participant W as FastAPI /webhook
    participant IG as IdempotencyGuard
    participant UL as 用户锁
    participant H as _handle
    participant RL as RateLimiter
    participant CMD as commands
    participant S as SessionStore
    participant P as RAG pipeline
    participant E as embeddings
    participant Q as Qdrant
    participant LLM as Ark LLM
    participant CH as channel(Twilio)

    U->>T: 发送问题
    T->>W: POST /webhook (MessageSid, From, Body)
    W->>IG: seen_or_mark(MessageSid)
    alt 已见过(重复投递)
        IG-->>W: true
        W-->>T: 200 空响应(丢弃)
    else 首次
        IG-->>W: false
        W->>W: add_task(_handle_serialized)
        W-->>T: 200 空响应(立即)
        T-->>U: （等待回复）

        W->>UL: 获取该用户锁
        activate UL
        UL-->>W: 加锁
        W->>H: _handle(sid, from, body)
        activate H
        H->>RL: allow(wa_id)
        RL-->>H: true
        H->>CMD: parse_command(body)
        CMD-->>H: None(普通问题)
        H->>S: state(wa_id)
        S-->>H: active
        H->>S: build_context(wa_id)
        S-->>H: 历史 turns
        H->>P: answer(question, history)
        activate P
        P->>E: embed_one(question)
        E-->>P: 向量
        P->>Q: search(向量, top_k)
        Q-->>P: hits(带 score)
        Note over P: 最高分 ≥ 阈值
        P->>LLM: chat(messages=系统+历史+问题)
        LLM-->>P: 答案
        P-->>H: AnswerResult(answered, sources, top_score)
        deactivate P
        H->>S: record_hit / add_turn(user+assistant)
        H->>CH: send_whatsapp(答案+来源+反馈提示)
        CH->>T: REST API 发消息
        T->>U: 收到回答
        deactivate H
        deactivate UL
    end
```

## 2. 无答案：拒答 + 连续 2 次自动转人工

```mermaid
sequenceDiagram
    autonumber
    participant U as 客户
    participant W as _handle
    participant S as SessionStore
    participant P as pipeline
    participant Q as Qdrant
    participant HO as handoff
    participant CH as channel
    participant D as 值班号码

    Note over U,D: 第 1 次答不出
    U->>W: 无关问题
    W->>P: answer()
    P->>Q: search()
    Q-->>P: hits
    alt 最高分 < 阈值 或 LLM 自陈无内容
        P-->>W: AnswerResult(no_match)
    end
    W->>S: add_turn(user / 拒答话术)
    W->>S: record_miss()
    S-->>W: miss_streak = 1
    W->>CH: 发送"没找到，可换问法或转人工"
    CH-->>U: 拒答回复

    Note over U,D: 第 2 次仍答不出 → 自动转人工
    U->>W: 另一个无关问题
    W->>P: answer()
    P-->>W: AnswerResult(no_match)
    W->>S: add_turn / record_miss()
    S-->>W: miss_streak = 2
    W->>CH: 发送拒答话术
    W->>HO: trigger_handoff(reason=auto_no_answer)
    HO->>S: 取最近上下文
    HO->>CH: send_whatsapp(ON_DUTY_NUMBER, 问题+上下文)
    CH->>D: 收到转人工通知
    alt 主号失败且配了备用号
        HO->>CH: 发送 ON_DUTY_FALLBACK_NUMBER
    else 未配置/都失败
        HO-->>W: false
    end
    W->>CH: 发送"已通知值班人员"/"暂无值班人员"
    CH-->>U: 收到确认
```

## 3. 指令分支（帮助 / 重置 / 问候 / 反馈）

```mermaid
sequenceDiagram
    autonumber
    participant U as 客户
    participant H as _handle
    participant CMD as parse_command
    participant S as SessionStore
    participant CH as channel

    U->>H: 发送消息
    H->>CMD: parse_command(body)
    CMD-->>H: Command(type, value)

    alt type = help
        H->>CH: 发送 HELP 菜单
    else type = reset
        H->>S: reset(wa_id)
        H->>CH: 发送"已重新开始"
    else type = greeting（你好/hi/在吗）
        alt 会话已存在
            H->>S: add_turn(寒暄)
            H->>CH: 发送"你好！有什么可以帮你？"
        else 新用户
            H->>S: add_turn(欢迎语)
            H->>CH: 发送 WELCOME 欢迎语
        end
        Note over H: 不调用 RAG
    else type = feedback (👍/👎)
        H->>S: try_mark_feedback(wa_id, value)
        alt 本轮首次反馈
            S-->>H: true
            Note over H: 记录结构化日志(rating)
        else 已评价过
            S-->>H: false(去重)
        end
        H->>CH: 发送"感谢反馈"
    else type = handoff
        H->>H: _do_handoff(customer_request)
    end
    CH-->>U: 收到对应回复
```

```mermaid
sequenceDiagram
    autonumber
    participant T as Twilio
    participant W as /webhook
    participant IG as IdempotencyGuard
    participant BG as 后台任务

    T->>W: POST /webhook (MessageSid=SM1)
    W->>IG: seen_or_mark(SM1)
    IG-->>W: false(首次)
    W->>BG: add_task(_handle_serialized)
    W-->>T: 200 OK

    Note over T,BG: 因超时/网络抖动，Twilio 重试同一消息
    T->>W: POST /webhook (MessageSid=SM1)
    W->>IG: seen_or_mark(SM1)
    IG-->>W: true(已存在)
    Note over W: 直接返回，不加入后台
    W-->>T: 200 OK(空)
    Note over BG: 只有一个后台任务在跑，不会重复回复
```

## 5. 新用户欢迎与会话过期

```mermaid
sequenceDiagram
    autonumber
    participant U as 客户
    participant H as _handle
    participant S as SessionStore
    participant CH as channel
    participant P as pipeline

    Note over U: 场景 A：全新用户首次提问
    U->>H: "年假有几天？"
    H->>S: state(wa_id)
    S-->>H: absent
    H->>CH: 发送 WELCOME 欢迎语
    H->>P: answer() 正常问答
    P-->>H: 答案
    H->>CH: 发送答案
    H->>S: add_turn 写入会话

    Note over U: 场景 B：7 天未对话后再来
    U->>H: "那病假呢？"
    H->>S: state(wa_id)
    Note over S: now - last_active > 7天<br/>删除旧会话
    S-->>H: expired
    H->>CH: 发送"已重新开始，请再说一下问题"
    H->>P: answer() 作为新问题处理
```

## 6. RAG 内部时序（pipeline.answer）

```mermaid
sequenceDiagram
    autonumber
    participant Caller as main._answer_question
    participant P as pipeline
    participant ST as store
    participant E as embeddings
    participant Q as Qdrant
    participant LLM as Ark

    Caller->>P: answer(question, history)
    P->>ST: count_points()
    alt 知识库为空
        ST-->>P: 0
        P-->>Caller: AnswerResult(empty_kb)
    else
        P->>E: embed_one(question)
        E-->>P: qvec
        P->>Q: query_points(qvec, top_k)
        Q-->>P: hits(score, payload)
        alt 无命中
            P-->>Caller: AnswerResult(no_match)
        else 最高分 < 阈值
            P-->>Caller: AnswerResult(no_match, top_score)
        else 相关性达标
            P->>P: 拼 system(资料+来源要求) + history + 当前问题
            P->>LLM: chat.completions.create()
            LLM-->>P: 回复文本
            alt 回复含"资料里没有相关内容"
                P-->>Caller: AnswerResult(no_match)
            else 正常
                P->>P: 截断到 answer_max_chars
                P-->>Caller: AnswerResult(answered, reply, sources, top_score)
            end
        end
    end
```

## 关键设计要点

- **webhook 立即 200**：所有耗时操作（检索/LLM/回发）都在后台，避免 Twilio 超时重试。
- **同步幂等**：MessageSid 检查在加入后台任务之前完成，杜绝重复回复。
- **用户级串行锁**：同一用户的消息排队处理，防止并发导致重复欢迎语、会话错乱。
- **两道拒答防线**：检索分数低于阈值不调 LLM；LLM 自陈无内容也按拒答处理。
- **单 worker**：会话/幂等/限流都在进程内存，必须 `--workers 1`。
